# Portfolio React – mIARINA

Un portfolio personnel créé avec React.js, pour présenter mes compétences, mes projets et me contacter facilement.

---

## 🌜 Technologies utilisées

* React.js (Create React App)
* CSS standard
* Flexbox et responsive design
* Déploiement possible sur Netlify, Vercel ou GitHub Pages

---

## 📂 Structure du projet

```
src/
 ├── assets/          # Images et ressources
 ├── components/      # Composants réutilisables (Navbar, Footer, ProjectCard, SkillBadge)
 ├── pages/           # Pages principales (About, Projects, Skills, Contact)
 ├── styles/          # Fichiers CSS organisés (components / pages)
 └── App.jsx           # Point d’entrée principal
```

---

## 🚀 Installation

### 1. Cloner le projet

```
git clone <url-du-projet>
cd nom-du-projet
```

### 2. Installer les dépendances

```
npm install
```

### 3. Lancer le serveur de développement

```
npm start
```

Le projet sera disponible sur : [http://localhost:3000](http://localhost:3000)

## ⚡ Scripts utiles

| Commande      | Description                                          |
| ------------- | ---------------------------------------------------- |
| npm start     | Démarre l’application en mode développement          |
| npm test      | Lance les tests                                      |
| npm run build | Prépare l’application pour la production             |
| npm run eject | Éjecte la configuration (à utiliser avec précaution) |

## 📌 Bonnes pratiques appliquées

* CSS séparé pour chaque composant et page (components/ et pages/)
* Responsive design avec Flexbox
* Images et assets centralisés dans src/assets
* Composants réutilisables pour éviter les répétitions
* Git branch dédié pour le développement (dev ou feature/...)
